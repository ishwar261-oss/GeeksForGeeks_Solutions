# Largest Element in an Array

## Problem

Find the largest element in the given array.

## Example

```text
Input:
[10, 5, 20, 8, 15]

Output:
20
```

## Approach

Assume the first element is the largest.

Then compare every remaining element with `maxi`.


## Complexity

- **Time:** O(n)
- **Space:** O(1)

## Key Concept

Maintain the maximum value while traversing the array.
