# Multiply Left and Right Array Sums

**Difficulty:** Basic  
**Points:** 1  
**Accuracy:** 62.84%

## Problem

Given an array of integers `arr[]`, divide it into two subarrays:

- `left` contains the first half of the elements.
- `right` contains the remaining elements.
- If the array size is odd, `right` contains one extra element.

Find the sum of both subarrays and return the **product of their sums**.
