# Minimum and Maximum in an Array

## Problem

Find both the minimum and maximum elements of an array.

## Example

```text
Input:
[7, 2, 9, 4, 1]

Output:
Minimum = 1
Maximum = 9
```

## Approach

Maintain two variables:

```text
mini
maxi
```

For every element, update both values.

## Complexity

- **Time:** O(n)
- **Space:** O(1)

## Key Concept

Find minimum and maximum in a single traversal.
