# Sum of Natural Numbers

## Problem
Given a number N, find the sum of first N natural numbers.

## Approach
The sum of natural numbers can be calculated using the mathematical formula:

Sum = N * (N + 1) / 2

## Algorithm
1. Take input N.
2. Apply the formula N*(N+1)/2.
3. Return the result.

## Complexity Analysis

Time Complexity: O(1)

Space Complexity: O(1)
